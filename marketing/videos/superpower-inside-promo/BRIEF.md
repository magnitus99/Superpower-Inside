이 파일은 작품별 brief·개정·출력 이력이다. 지속 계약은 [마케팅 스펙](../../SPEC.md)이 소유하며 아래 코드·자산 경로는 로컬 제작 환경에만 존재할 수 있다. 당시 완료한 렌더와 합성 화면을 현재 제품 성능이나 공개 게시 완료로 해석하지 않는다.

## 현재 적용 기준 · 2026-10-14

1차 목표는 다운로드·설치다. 지속 지침은 [마케팅 AGENTS.md](../../AGENTS.md), 조사·설득 구조는 [video-plan.md](../../video-plan.md), 표현 방향은 [visual-tone.md](../../visual-tone.md)를 따른다. 현재 제작본은 64초, 9장면의 한영 광고다. 35–45초에는 실제 제품의 합성 레이아웃 예시를 크게 보여 주며 핵심 강조 3회에 작은 클릭 효과음을 사용한다. 문구·화면·효과·길이의 변화는 사용자 결과와 설치 판단에 연결한다.

## 공식 기능 확장 · 2026-10-14

- [공식 저장소](https://github.com/heygen-com/hyperframes)를 확인하고 기존 CLI 0.8.152·GSAP·로컬 렌더 체제를 유지했다.
- 공식 `general-video` 스킬과 `text-match-cut`, `panel-reveal`, `ui-3d-reveal` 레지스트리 항목을 추가했다. 첫 문구의 연결 전환과 절제된 원근 진입에 패턴을 적용했다. 외부 제품이 들어 있는 `ui-3d-reveal` 전체 예시는 `.hyperframes/registry-reference/`에 보관하고 광고에는 탑재하지 않는다.
- `media-use`의 번들 클릭 음원, 볼륨·페이드 자동화, `index.motion.json`의 등장·프레임 유지 검사를 추가했다. 음악·나레이션·외부 유료 생성은 추가하지 않았다.
- 실제 UI는 별도 Obsidian 프로필·볼트에 독립 합성 데이터를 표시해 촬영했다. 모델 호출이 없는 레이아웃 예시이며 출처는 `assets/product/provenance.json`이다. 테스트 볼트와 사용자 설정은 사용하지 않았다.
- 사용자의 완료 요청에 따라 한영 최종 MP4 출력을 완료했다. 템포는 72초에서 64초로 높였으며 가치 중심 방향은 유지한다. `renders/superpower-inside-{ko,en}-final.mp4`가 최신 출력이다.

아래 이전 기획과 날짜별 개정 기록은 이력이다. 42초 제한·근거 시연 중심·모든 답변에 출처가 있다는 약속·스트리밍 표현·하단 재현 표기를 현재 제작 기준으로 사용하지 않는다.

## 과거 Intent · 현재 기준에서 제외

Obsidian 데스크톱 플러그인 Superpower Inside의 대문 홍보 영상. 문서가 많은 볼트를 쓰는 파워 유저에게, AI 답변의 근거를 노트에서 바로 열어 확인하는 경험을 보여준다. 톤은 차분한 에디토리얼 미니멀리즘 — 화려한 SaaS 광고가 아니라 문서가 스스로 증언하는 영상. 온스크린 텍스트가 메시지를 전달하고 나레이션은 없다.

## 2026-10-13 · README와 제품 철학 반영

- 현재 README.md의 작업 중심 소개와 product-philosophy.md의 최소 관여·맥락 연결을 기준으로 개정한다.
- 핵심 메시지: 내 자료에서, 다음 작업으로. 필요한 결과를 이야기하고, 관련 구간을 연결하고, 필요할 때 근거를 확인하고, 같은 대화에서 결과를 활용한다.
- 기존 1920×1080·41초·한영 파생본·무음·차분한 편집 톤을 유지한다.
- 모든 답변에 출처가 있다는 약속은 하지 않는다. 출처 확인이 정확성 보증이라는 표현을 쓰지 않는다.
- 답변은 모아서 수신한다. 결과 삽입은 사용자가 선택한다. 로컬 검색/OCR과 원격 채팅의 데이터 경계를 구분한다.

## 2026-10-14 · 사용 가치 중심 재설계

- 사용자 요청: 폰트·디자인 전면 개정, 하단 재현 데모 표기 제거, 중요한 가치에 집중된 효과, 작동 원리보다 사용자 성과와 제품 방향성, 길이 확장 허용.
- 72초·1920×1080·한영·나레이션 없음. 기존 제품 화면 재현과 가상 파일 예시는 전부 제거한다.
- 현재 기능 약속: README의 프로젝트 복귀·비교·집필·근거 확인·모델 선택. 지향점은 제품 철학 P01·P04·P09에서 가져오며 '우리가 만드는 경험'으로 구분한다.
- 이전 41초: 어두운 에디터·얇은 세리프·절차 시연. 이번 72초: 따뜻한 밝은 배경·굵은 Pretendard/Inter·사용 가치 장면·핵심 3회 강조.
- 조사: Google ABCD https://support.google.com/google-ads/answer/14783551?hl=en , Wistia https://wistia.com/blog/optimal-video-length . 72초는 이 제품의 읽기·서사 길이를 고려한 제작 판단이며 보편적 최적 길이로 주장하지 않는다.
- 장면: 0–7 다음 생각 / 7–14 필요한 결과 / 14–23 프로젝트 복귀 / 23–32 비교 / 32–40 근거 / 40–50 글쓰기 / 50–58 방향성 / 58–64 선택 / 64–72 설치.
- 효과: marker-highlight 밑줄을 다음 생각·판단의 근거·생각에 쓸 여유에만 적용한다. 방향성 장면에서는 배경으로 물러나는 준비와 또렷한 생각을 선택적 초점으로 구분한다.
