# Superpower Inside — 홍보 영상 기획과 제작 기록

이 문서는 작품별 판단·조사·사용자 피드백·렌더 이력을 보존하는 참고 자료다. 지속 계약의 정본은 [마케팅 스펙](SPEC.md), 브랜드 표현은 [visual-tone.md](visual-tone.md), 실제 앱 UI는 [design.md](../design.md)다. 아래 기준일의 제작본을 현재 제품 기능·성능·전환 효과로 일반화하지 않는다.

- 기준 갱신: 2026-10-14.
- 1차 목표: 영상을 본 사람이 제품을 다운로드·설치하는 것.
- 실행 지침: [AGENTS.md](AGENTS.md). 공개 소개는 [README.md](../README.md), 실제 제품 사실은 구현·호출부와 대조하고 지향점은 [제품 목표의 가치·원칙](../goal-and-requirements.md#가치와-원칙)에서 구분한다.
- 검토한 텍스트만 공유하며 렌더·캡처·폰트·코드·도구 상태는 계속 Git에서 제외한다.

## 이번 메시지

**내 자료에서, 다음 작업으로.** 타깃과 약속의 지속 기준은 `marketing-contract`에 이전했다. 이 메시지는 아래 작품의 카피 선택이며 모든 후속 작품의 고정 문장이 아니다.

참조 확인일: 2026-10-14. 세부 통계나 최신 권고를 다시 인용할 때는 원문을 재확인한다. '애플 광고처럼 사용자 변화와 제품 방향성을 앞세우기'는 사용자의 창작 방향 요청이다. 이번에 특정 애플 광고를 직접 분석하거나 그 전환율을 확인한 것으로 기록하지 않는다.

## 사용자의 직접 요청과 지적

- 폰트와 디자인 언어 전체를 제품 철학에 맞게 다시 다듬는다.
- 하단의 '재현 데모 · 가상 문서' 표기를 지운다.
- 문구만 바꿔 이전과의 차이를 느끼기 어려운 개정을 반복하지 않는다.
- 정말 중요한 순간에 효과를 주고 마케팅 스윗 스팟을 다시 검토한다.
- 작동 원리보다 사용자가 얻는 것과 제품이 추구하는 방향성을 담는다.
- 설득력·흡입력이 있으면 45초를 넘겨 1분·2분으로 늘려도 된다.
- 다운로드가 1차 목표다. 이를 위해 실제 제품 디자인·UI/UX를 조금 보여 주는 편이 나은지 판단한다.
- 72초 개정본에는 '정말 좋은데'라는 긍정 피드백이 있었다. 이를 최종 출력 승인이나 전환 효과 검증으로 확대하지 않는다.
- 광고로 생각하고 다운로드 설득을 우선한다. 실제 UI의 포함 여부는 제작 판단에 맡기며 기존 방향을 유지하면서 템포를 조금 높인다. 공식 HyperFrames 기능 중 필요한 것을 추가해 품질을 높인다.

## 이번 구성의 선택

지속적인 설득·주장 경계는 `marketing-contract`에 이전했다. 당시 에이전트의 UI 권장안은 8–12초 한 구간이었고 이번 작품은 10초 글쓰기 장면을 선택했다. 아래 현재 제작표와 과거안은 그 선택의 이력이며 영구적인 UI 비율이 아니다.

## 현재 제작본과 남은 선택

현재 컴포지션은 1920×1080, 한영, 9장면, 64초의 가치 중심 광고다. 실제 제품 화면과 핵심 강조에 맞춘 작은 효과음을 포함한다. 나레이션과 음악은 없다. 이는 이번 상태이며 이후 영상의 영구 기본값은 아니다. 표현 방향은 [visual-tone.md](visual-tone.md), 정확한 토큰은 [frame.md](videos/superpower-inside-promo/frame.md)에 있다.

| 시간 | 전달하는 가치 | 현재 장면 |
| --- | --- | --- |
| 0–6초 | 모아 둔 자료로 다음 생각 시작 | 브랜드와 핵심 약속 |
| 6–12초 | 파일명을 모두 기억하지 않고 결과로 시작 | 필요한 결과를 말하는 문구 |
| 12–20초 | 멈췄던 프로젝트 이어 가기 | 결정·질문·다음 행동 |
| 20–28초 | 따로 읽던 자료를 함께 이해하기 | 동의·차이·남은 질문 |
| 28–35초 | 중요한 판단의 근거 확인 | 근거 강조 |
| 35–45초 | 빈 페이지를 내 자료로 시작하기 | 실제 제품의 개요·노트 링크 |
| 45–52초 | 수고보다 생각에 주의를 두는 방향 | '우리가 만드는 경험' |
| 52–57초 | 사용할 AI 선택 | 제공자·모델 선택 |
| 57–64초 | 다운로드·설치로 이어지기 | 설치 주소와 무료·비용 조건 |

64초는 읽기 시간을 보존하면서 정지 구간을 줄인 제작 판단이다. 최적 길이나 전환율 개선이 실험으로 검증된 것은 아니다. 한영 최종 MP4를 1920×1080·30fps로 출력하고 화면·길이·효과음 3회의 음량을 확인했다. 결과 파일은 영상 프로젝트의 `renders/superpower-inside-ko-final.mp4`와 `renders/superpower-inside-en-final.mp4`다.

## 이전안에서 교정한 것

| 이전 기준 | 최신 기준 |
| --- | --- |
| 30–45초를 사실상 상한으로 삼음 | 설득력과 읽기 시간에 따라 길이 선택 |
| 근거 시연·검증 배지 중심 | 사용 가치와 방향성 중심, 근거는 이를 지지 |
| 어두운 에디터·세리프·좁은 패널 | 이번 브랜드 그래픽은 밝은 여백·굵은 산세리프 |
| 기능 설명용 재현 UI | 필요한 경우 짧은 실제 화면으로 신뢰 보강 |
| '모든 주장에 출처', 스트리밍 묘사 | 실제 지원 범위와 모아서 받는 응답을 정확히 표현 |

이전의 근거 중심 포지셔닝과 경쟁 제품에 대한 단정은 현재 기준으로 사용하지 않는다. 설치 행동은 [Obsidian 설치 페이지](https://obsidian.md/plugins?id=superpower-inside) 또는 [최신 릴리스](https://github.com/magnitus99/Superpower-Inside/releases/latest)로 연결한다.

## 효과를 판단하는 근거

게시 후 확보 가능한 범위에서 설치 링크 클릭·다운로드·실제 설치를 구분해 본다. 조회·완주가 높다고 다운로드가 늘었다고 판단하지 않는다. 측정·비교 실험 전에는 '검증된 스윗 스팟'이나 '전환율이 개선된 영상'이라고 표현하지 않는다.
