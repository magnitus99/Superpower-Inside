# 사용 가치 전달과 마케팅 계약

## 목표와 메시지

1차 목표는 제품 다운로드·설치다. 기능 설명의 완전성이나 영상 길이 자체를 목표로 삼지 않는다. Obsidian에 자료를 모아 조사·학습·비교·집필하는 사람에게 프로젝트 복귀·자료의 비교와 이해·내 자료로 글쓰기를 통해 다음 작업을 이어 가는 가치를 먼저 전달한다. 근거 확인은 그 판단을 돕는 가치이며 타깃을 근거 검증만 원하는 사람으로 축소하지 않는다.

초반부터 사용자가 얻는 변화와 결과를 보여 준다. 내부 처리·검색 로그·설정 과시 대신 목적 → 공감할 작업 결과 → 필요한 실제 제품 증거 → 제품 방향 → 설치 행동으로 연결한다. `superpower-goals`의 최소 관여·목적과 결과 중심의 주의·정돈된 사용 경험을 참고하되 지향점을 구현 성과로 표현하지 않는다.

## 주장과 제품 화면의 경계

제품 사실은 현재 구현·호출부와 대조하고, 앱 UI는 `interface-design`, 브랜드 표현은 `brand-video-expression`을 따른다. 특정 브랜드 광고의 외형·문구·자산을 복제하거나 브랜드 참조만으로 전환 효과를 주장하지 않는다.

실제 UI는 사용법 전체의 설명보다 설치 후 경험을 구체화하는 증거다. 답변·출처·노트 활용을 크게 읽히게 보여 주며, 실제 촬영·합성 레이아웃·창작 그래픽·미촬영 자리를 구분한다. 합성 대화를 실제 제품 렌더러에 표시한 예시는 모델 응답·성능 증명이 아니다. 제품에 없는 UI·저장·수신 동작을 창작해 실제 기능처럼 제시하지 않는다. 촬영 자료는 실제 볼트와 독립적이며 데이터 보호·자동화 제한은 `engineering-contract`를 따른다.

모든 답변·주장에 출처가 있다거나 출처 확인이 정확성을 보장한다고 약속하지 않는다. 무료 플러그인과 제공자 비용, 로컬 검색/OCR과 원격 채팅 전송 조건은 `release-contract`의 사용자 약속 경계를 따른다.

## 표현·길이·효과의 판단

개정 요청에는 실제 화면·서사·서체·리듬의 변화가 있어야 하며 문구만 바꾼 결과를 전면 개정으로 보고하지 않는다. 중요 순간에 선택적으로 강조하고 읽기 시간을 보존한다. 조금 빠른 광고 템포와 편안한 흐름을 함께 검토한다. 45초를 상한으로 삼지 않으며 길어지는 각 장면이 공감·가치·증거·행동에 무엇을 더하는지 판단한다.

8–12초의 UI 구간, 특정 64초안, 서체·팔레트·음악 유무는 작품별 선택이지 영구 규칙이 아니다. 한영은 같은 약속을 전달하되 길이·줄바꿈·폰트·화면을 각각 확인한다. 화면 검수·렌더 성공·도구 설치를 마케팅 효과로 주장하지 않는다.

Google ABCD 등 외부 조사는 방향의 근거이며 이 제품의 최적 길이·서체·전환율을 입증하지 않는다. 출처·당시 확인일·한계와 제작 이력은 [video-plan.md](video-plan.md), 합성 장면·촬영 한계는 [scenario.md](scenario.md)에 보존한다. 조회·완주·클릭·다운로드·설치를 구분해 측정한 범위만 보고한다.

## 커뮤니티 목록

커뮤니티 목록 문구는 기능 설명보다 검색 발견을 겨냥해 쓴다. 핵심 단서를 짧은 설명에 배치하고 후보를 제시한 뒤 실제 반영은 사용자가 판단한다. 한국어 전용 이미지를 따로 만들지 않고 필요하면 영어 화면 옆·아래에 병기한다. 게시·편집·저장은 별도 요청 범위다.

## 배포와 제작 권한

설치 행동은 [Obsidian 설치 페이지](https://obsidian.md/plugins?id=superpower-inside) 또는 [최신 릴리스](https://github.com/magnitus99/Superpower-Inside/releases/latest)로 연결한다. 커뮤니티의 영상 임베드는 기존 MP4를 유지하고 필요하면 재생 버튼이 있는 정적 PNG에 원본 영상 링크를 연결한다. GIF로 변환하지 않는다.

렌더·게시·외부 편집·새 자산 설치는 문서 정리 요청에 포함되지 않는다. 실제 영상 작업은 현재 HyperFrames 진입 스킬과 해당 프로젝트 지침을 따르며 설치본 스킬을 이 문서로 복제하지 않는다. 현재 제작안·과거 조사·게시 카피는 참조이며 새 실행 권한이 아니다.
