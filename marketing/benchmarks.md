# 근거를 찾는 능력을 숫자로 확인하기

Superpower Inside의 평가 대상은 하나의 제품입니다. 실제 Obsidian 볼트에서 평소 사용하는 채팅을 실행하고, 답변이 질문을 해결했는지와 인용한 원문이 그 답변을 뒷받침하는지를 함께 측정합니다.

문서 청킹·임베딩·BM25·하이브리드 검색·볼트 도구·최종 답변은 설치된 제품의 구현과 현재 선택한 설정을 사용합니다. 기존 노트의 인덱스와 캐시를 보존하고 공개 코퍼스 밖의 문서가 답변에 섞이지 않도록, 평가 데이터의 인덱스와 임베딩 캐시를 별도 저장소에 만듭니다. 검색 구성요소별 점수를 제품 비교표의 별도 행으로 내세우지 않습니다.

현재 새 평가 경로를 검증하고 있습니다. 이전의 소규모 BM25·도구 루프 비교 결과는 제품 전체의 성능 수치로 사용하지 않습니다.

| 공개 벤치마크                                                              | 확인하는 능력                                           | 평가 범위                                                                                          |
| -------------------------------------------------------------------------- | ------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| [WixQA](https://huggingface.co/datasets/Wix/WixQA)                         | 질문과 표현이 다른 도움말에서 정확하고 완전한 답을 찾기 | 문서 6,221개, expert 200문항과 simulated 200문항을 각각 보고                                       |
| [EnterpriseRAG-Bench](https://github.com/onyx-dot-app/EnterpriseRAG-Bench) | 여러 문서의 근거 결합, 충돌·조건·정보 부재 처리         | 전체 핵심 500문항. 같은 ID를 공유하는 원문도 보존. metadata 추가 100문항은 공식 기본 평가에서 제외 |

WixQA synthetic 질문은 주 지표에 섞지 않습니다. Enterprise의 특정 출처만 사용한 실행은 전체 리더보드 결과와 구분해 표시합니다. 공개 데이터는 MIT 라이선스와 출처를 확인한 자료이며, WixQA의 출처는 **Wix.com AI Research**입니다.

다음은 2026년 10월 11일 확인한 외부 공개 수치입니다. 경쟁 제품을 설치해 직접 측정한 결과가 아닙니다.

Enterprise의 종합 점수는 질문별 **정답 여부 × 필수 사실 충족률**의 평균입니다. 정확도, 완전성, 정답 문서 재현율과 다른 지표입니다. 평가기는 공식 프롬프트와 산식을 사용하며, 원본 정답을 고정하는 `no-correction` 조건과 선택한 판정 모델을 기록합니다. 조건이 다른 수치를 이용해 순위나 경쟁 우위를 주장하지 않습니다.

README에는 검증을 마친 데이터셋별 점수, 질문 수, 반복 횟수, 모델과 평가일을 함께 제시합니다. 제품 페이지에는 비교표에서 실제 답변과 인용 구간을 볼 수 있도록 연결하고, 조건이 붙는 수치는 그 조건을 가까이 표시합니다. 대표 사례는 미리 고정한 질문에서 선택하며 실패 사례와 전체 결과도 함께 제공합니다.

재현은 현재 선택한 모델과 임베딩 설정을 그대로 사용합니다. 테스트 볼트에서 플러그인을 활성화한 상태로 실행합니다.

```fish
npm run bench:public -- download
npm run bench:public -- prepare-wix
npm run bench:public -- prepare-enterprise
npm run bench:public:native -- wix all full 3
```

실행 기록과 Markdown 비교표는 Git에서 제외한 `.test-vault/.benchmarks/native-runs/`에 저장합니다. 생성한 공개 코퍼스와 평가용 채팅은 실행 종료 후 제거하며 기존 노트·설정·세션은 보존합니다. 결과를 재개할 때 데이터·설정·제품 빌드가 바뀌면 서로 다른 실행으로 처리합니다.

각 실행은 원문 체크섬, 제품 빌드와 설정의 지문, 질문 수와 반복 횟수를 기록합니다. 실패와 판정 미완료를 성공률의 분모에서 빼지 않으며, 반복 실행의 신뢰구간은 같은 질문을 한 묶음으로 계산합니다. 공식 정답 문서 재현율, 답변 정확도, 필수 사실 충족률, 실제 인용 구간의 뒷받침 여부와 응답 시간을 각각 공개합니다.

추가 질문 카드는 화면에 표시되는 질문과 선택지까지 수집하되 최종 답변 성공으로 계산하지 않습니다. 응답 중 창의 가시 상태도 기록하며, 창이 숨겨져 타이머 제한을 받은 실행은 정상 사용 시의 속도 주장에 사용하지 않습니다.

근거 판정에는 실제 답변 아래에 표시된 출처 카드의 검증된 줄 구간을 사용합니다. Markdown 링크와 출처 ID 중 어느 표기를 썼는지에 따라 근거를 놓치지 않도록, 문서 경로·줄 범위·원문 체크섬을 확인한 뒤 해당 원문만 판정기에 전달합니다.
