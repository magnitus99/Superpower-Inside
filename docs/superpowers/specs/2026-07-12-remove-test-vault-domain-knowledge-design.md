# 테스트 볼트 도메인 지식 제거 설계

## 목적

공용 플러그인의 제품 코드, 테스트, 개발 지침에서 특정 개인 테스트 볼트에만 유효한 지식과 상태를 제거한다. 검색 및 컨텍스트 선택 로직은 볼트 내용과 무관한 일반 계약만 유지한다.

## 제거 범위

- Rust/WASM 제품 코드의 특정 도메인 한국어·영어 고정 대응표를 삭제한다.
- 테스트에서 개인 볼트의 인물, 문헌, 폴더명과 질문을 중립적인 가상 fixture로 교체한다.
- `AGENTS.md`에서 개인 테스트 볼트의 파일명, 코퍼스, 저장 채팅, 벡터 규모와 런타임 상태를 제거한다.
- 채팅 근거화 설계·계획 문서에서 실제 테스트 볼트의 규모와 도메인 질문을 제거한다.

## 유지 범위

- 모델이 질문 문맥에 따라 검색어를 일반적으로 확장하는 기능은 유지한다. 특정 분야의 번역어나 동의어를 코드에 고정하지 않는다.
- 빈 개발 볼트를 생성하고 Obsidian에서 플러그인을 검증하는 setup/debug 도구와 일반 QA 절차는 유지한다.
- 검색, 암묵적 폴더 감지, lexical evidence 순위화의 도메인 독립적 동작은 유지한다.

## 검증

- 추적 파일 전체에서 제거 대상 개인 도메인 문자열과 고정 단어집이 남지 않았는지 검색한다.
- 변경된 Rust/WASM 및 TypeScript 계약 테스트를 중립 fixture로 검증한다.
- 린트, 타입체크, 테스트를 거친 뒤 `npm run security:full`, `npm run build`, manifest 버전 기반 community review gate를 순서대로 실행한다.
