# 소프트웨어 보조 사례: 승인된 고객 가치를 구현으로 옮길 때

사용자가 지정한 세 브랜드가 중심 참조다. 아래 도구는 그 가치의 실제 소프트웨어 대응과 실패 가능성을 확인하는 보조 자료다. 기능·상품 모델을 채택하자는 제안은 아니다.

| 제품 | 관찰한 연결 | 드러나는 절충·한계 | 출처 |
| --- | --- | --- | --- |
| Obsidian | 사용자 파일과 장기 활용을 중심에 둔다 | 플러그인·외부 모델의 전송 경로까지 로컬로 보장하지 않는다 | SW01 |
| Zotero | 주석→노트/문서→원문 위치를 연결 | 인용 링크는 주장 자체의 정확성 보증과 다르다 | SW02·SW03 |
| Readwise | 읽기 중 선택한 내용을 지식 작업으로 이어 준다 | 덮어쓰기 방지가 기존 하이라이트 수정 전파와 충돌할 수 있다 | SW04·SW05 |
| DEVONthink | 자료 검색·연결과 선택적 생성 기능 | 기능이 많아도 시작할 경로를 찾기 어려울 수 있다 | SW06·SW07 |
| NotebookLM | 제공한 자료로 설명을 얻고 근거에 돌아간다 | 출력 저장 뒤 출처 이동의 기대가 어긋났던 역사 사례 | SW08·SW09 |
| Scrivener | 구조 변경과 원고 순서, 참고 자료와 집필을 연결 | 전체 기능 습득보다 현재 작업에 필요한 연결이 중요하다는 해석 | SW10·SW11 |
| Copilot | 현재 문서는 에이전트 작업과 가벼운 작업을 구분 | 과거 검색 준비·관련성 불만을 현재 버전의 결함으로 단정하지 않는다 | SW12·SW13 |
| Smart Connections | 로컬 의미 검색과 다른 데이터 경로를 구분 | 업데이트·플러그인 로드가 준비 경험을 막았던 사례 | SW14·SW15 |
| Smart Composer | 자료 참조와 편집 적용의 연결 | 포괄적인 제품 소개를 전체 볼트 완독이나 무오류로 확대하지 않는다 | SW16·SW17 |

ID의 상세 근거는 [공식](../sources/official.md)과 [커뮤니티](../sources/community.md)에 있다. 경쟁 도구의 전송·키 저장·편집 권한 계약을 우리 계약으로 가져오지 않는다.

## 개발에 참고할 연구

- [RS01](../sources/research.md#rs01)은 추상적인 신뢰를 능력 설명·수정·제어·상호작용 유지 같은 관찰 가능한 행동으로 나누는 데 유용하다.
- [RS02](../sources/research.md#rs02)는 편리한 연결과 자료 소유가 함께 성립해야 한다는 P13 후보에 참고한다. 로컬 저장만으로 백업·보존 문제가 해결된다고 약속하지 않는다.
- [RS03](../sources/research.md#rs03)은 실제 반응 경험을 측정할 이유다. 웹 인터랙션의 숫자를 모든 모델·OCR 실행의 시간 제한으로 복제하지 않는다.

이번 조사에서는 이 도구들을 설치·실행하거나 모델 답변을 비교하지 않았다. 문서·사용 경험만을 읽었으며 실제 우리 제품의 성능·품질 향상은 검증하지 않았다.
