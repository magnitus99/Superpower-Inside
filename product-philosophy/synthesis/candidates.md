# 제품 철학 후보와 정리 결과

15개 조사 후보를 승인 5개·기존 범위 9개·중복 제외 1개로 정리했다. 기존 범위와 제외 항목은 새로운 사용자 승인으로 세지 않는다. 사용자 승인 문장·조건만 확정 기준이며, 조사 원문과 적용 예시는 구분한다. 전체 연결은 [결정 데이터](../decisions/status.json), 보완 관점은 [선행 근거 보강](evidence-perspectives.md)에서 확인한다.

## P01

### 최소한의 관여로 목적을 이룬다

**상태: 사용자 승인**

**승인 문장:** 제품은 사용자의 의도와 기존 맥락·설정·권한을 바탕으로 자동화할 수 있는 판단과 작업을 최대한 맡아, 최소한의 관여로 목적을 이루게 한다. 목적 표현·자료 선택·결과 검토도 고정된 수작업으로 남기지 않는다. 제품이 처리할 근거가 부족하거나 사용자의 결정이 반드시 필요한 지점에서만 관여를 요청한다. 준비부터 결과 활용까지 맥락과 근거를 연결하고 실패 시 기존 작업을 보존한다.

**승인 조건:**

- 사용자의 역할을 목적 입력·자료 선택·결과 검토의 고정 수작업으로 정의하지 않는다. 기존 의도·맥락·설정·권한으로 처리 가능한 부분은 최대한 자동화한다.
- 사용자의 의도나 필요한 결정의 근거가 부족하면 관여를 요청하되 제품이 먼저 확인·처리할 수 있는 일을 떠넘기지 않는다. 기존 권한·자료 보존 계약은 유지한다.
- 손가락 하나만 움직이는 수준은 최소한의 관여를 설명하는 사용자 지정 지향점이다. 실제 차량 성능의 주장이나 자동화 기능의 확정 명세가 아니다.
- 이번 범위는 철학 문장과 책임 범위의 수정·기록이다. idealisation과 구체적인 자동화 기능 구상·구현은 포함하지 않는다.

- 근거 ID: RR01 · RR02 · CA03 · AP05
- 반례·절충 ID: RR08
- 적용 예시: 기존 의도·맥락·설정으로 처리할 수 있는 자료 선택과 준비를 제품이 맡고, 필요한 선택이 남았을 때만 이유와 함께 요청한다.
- 어긋나는 예시: 모든 사용자에게 색인 방식·검색 엔진·추출 옵션 선택을 완료하도록 요구하거나 동의하지 않은 외부 전송을 실행한다.
- 확인할 실제 증거: 사용자 역할 중 자동화 검토 없이 남겨둔 수작업, 관여 요청의 필요성, 단계 간 맥락·근거 보존과 기존 권한 유지

## P02

### 사용자 수고를 줄이되 결과의 충실도를 희생하지 않는다

**상태: 사용자 승인**

**승인 문장:** 제품은 사용자의 수고를 줄이되, 그 대가로 결과의 충실도를 낮추지 않는다. 충분히 처리하지 못한 부분은 완료한 것처럼 제시하지 않는다.

**승인 조건:**

- 사용자는 이 항목을 모든 소프트웨어가 갖춰야 할 기본 자질로 해석했다. 제품의 차별적 철학이 아니라 기본 품질 조건으로 분류한다.
- BM25 전용 정책이나 구체적인 검색·대기·자동화 기능의 승인으로 확대하지 않는다.

- 근거 ID: RS01
- 반례·절충 ID: SW13
- 적용 예시: 처리한 범위와 부족한 범위를 구분하고, 제한된 결과를 전체 검토 완료처럼 제시하지 않는다.
- 어긋나는 예시: 빠르게 답하려고 확보하지 못한 근거까지 확인한 것처럼 답한다.
- 확인할 실제 증거: 요청한 범위·확보한 근거·완료 표시의 일치

## P04

### 제품의 노력보다 사용자의 작업과 결과가 전면에 온다

**상태: 사용자 승인**

**승인 문장:** 제품은 내부의 수고를 과시하지 않는다. 사용자의 주의는 목적과 결과에 머물게 하고, 판단에 필요한 정보는 필요한 순간에 명확하게 제공한다.

**승인 조건:**

- 정상적인 내부 처리는 반복적으로 주의를 요구하지 않는다. 판단·선택·문제 대응에 필요한 정보는 명확하게 제공한다.
- 자세한 과정은 사용자가 원할 때 확인할 수 있어야 한다. 조용한 경험을 이유로 실패와 중요한 제약을 숨기지 않는다.

- 근거 ID: RR12 · AP06 · RS01
- 반례·절충 ID: MB07
- 적용 예시: 정상 배경 작업은 방해하지 않고, 실패하면 원인·영향·가능한 행동을 현재 작업에서 확인한다.
- 어긋나는 예시: 정상 상태 팝업을 반복하거나 조용한 인상을 위해 실패와 외부 전송 조건을 숨긴다.
- 확인할 실제 증거: 작업 중 불필요한 방해 횟수, 중요한 상태·조건을 찾을 수 있는지

## P05

### 새 기능과 기존 개선을 전체 흐름의 편안함으로 판단한다

**상태: 사용자 승인**

**승인 문장:** 새 기능과 기존 개선을 모두 편안함을 높이는 수단으로 본다. 전체 사용 흐름에서 사용자의 부담을 더 줄이는 쪽을 선택한다. 새 기능이 더 큰 편안함을 만들면 도입하고, 그 과정에서 늘어나는 관리·판단 부담도 함께 평가한다.

**승인 조건:**

- 편안함을 높이는 새 기능을 적극적으로 추가할 수 있다. 기존 기능이 완벽해질 때까지 기다려야 한다는 조건을 두지 않는다.
- 몽블랑의 참조 의미는 엘레강스함과 사용성이다. 기능의 안정성이나 개발 우선순위를 브랜드 예시에서 사용자 의도로 도출하지 않는다.

**참조 범위:** 몽블랑은 엘레강스함과 사용성의 참조이며 개발 우선순위의 근거로 쓰지 않는다.

- 근거 ID: CW01 · CD02 · RR03 · AP05
- 반례·절충 ID: CW06 · AP08
- 적용 예시: 새 기능이 더 큰 편안함을 만들면 도입하고, 기존 개선이 더 큰 효과를 내면 그 개선을 앞세운다.
- 어긋나는 예시: 기존 기능 완성도를 이유로 새 기능을 일괄 보류하거나 새로움을 이유로 늘어난 부담을 무시한다.
- 확인할 실제 증거: 같은 사용자 목적에서 전후 관여·반복 입력·관리·판단 부담과 결과 활용, 기본 품질 유지

- 어긋나는 예시: 검색·답변·저장은 각각 성공하지만 저장된 결과에서 근거를 찾을 수 없어 사용자가 다시 검색한다.

## P07

### 사용자가 제품에 맞추기보다 제품이 사용자의 작업 방식에 맞춘다

**상태: 중복 독립 철학에서 제외**

**보존된 조사 문장 — 새 승인 기준이 아님:** 제품은 사용자의 언어·자료·작업 방식에 맞춰 자연스럽게 작동한다. 개인화를 사용자가 설정을 관리하는 일로 만들지 않고, 결과에 필요한 차이를 제품이 흡수한다. 기존 의도와 맥락으로 처리 가능한 부분은 맡고 사용자의 결정이 필요한 경우에만 선택을 요청한다.

개인 맞춤은 기존 임베딩·프롬프트 설정의 역할로 유지하며 별도 철학을 추가하지 않는다. [재검토 기록](p07-review.md)은 보조 자료다.

**참조 범위:** RR05는 취향·개인의 의미를 주문 결과로 구현한 사례다. AI의 자동 작업 적합성은 그 원문에서 직접 도출된 사실이 아니라 조사자의 추론이다. 몽블랑 참조 의도를 개인화 철학으로 확장하지 않는다.

- 근거 ID: RR05
- 반례·절충 ID: CW03
- 적용 예시: 자료 범위·언어·승인 수준처럼 결과에 중요한 선택은 유지하고 불필요한 엔진 설정은 일반 흐름에 강제하지 않는다.
- 어긋나는 예시: 선택이 많다는 이유로 개인화가 됐다고 보고, 어떤 값이 필요한지 사용자가 실험하게 한다.
- 확인할 실제 증거: 선택의 결과를 설명할 수 있는지, 서로 다른 자료·사용자에서 기본 경로가 성립하는지

## P09

### 쓰는 과정 자체의 만족을 고객 가치로 고려한다

**상태: 사용자 승인**

**승인 문장:** 제품을 쓰는 과정 자체에서 정돈됨과 세심함을 느끼게 한다. 유용한 결과와 편안한 흐름이 사용의 만족으로 이어져 다시 찾고 싶은 도구가 되게 한다.

**승인 조건:**

- 유용한 결과와 편안한 흐름이 정돈됨·세심함을 느끼는 사용 만족으로 이어지는 것을 고객 가치로 삼는다.
- 구체적인 장식·모션·새 기능의 승인으로 확대하지 않으며 기존 디자인 기준과 승인 조건을 유지한다.

**참조 범위:** Namiki 사용자가 보고한 촉감·균형·필기감의 만족과 Vitsœ/Rams의 미적·심리적 필요를 참고한다. 몽블랑의 사용자 지정 의미를 애착·소유 철학으로 확대하지 않는다.

- 근거 ID: CW05 · CD02
- 반례·절충 ID: MB06
- 적용 예시: 사용자가 자신의 근거 있는 결과와 진행을 확인하며 다시 쓰고 싶어지는 경험을 제공한다.
- 어긋나는 예시: 가치 없는 의식을 강제하거나 명품 표현·희소성만으로 실제 품질을 대신한다.
- 확인할 실제 증거: 사용자가 다시 사용하고 싶은 이유, 결과를 자기 작업으로 느끼는지; 행동 관찰과 인터뷰 필요
