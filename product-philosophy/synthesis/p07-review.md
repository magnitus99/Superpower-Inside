# P07 · 출발점과 우리 제품 적용의 간격

**현재 상태: 중복 독립 철학에서 제외.** 개인 맞춤은 기존 임베딩·프롬프트 설정의 역할로 유지한다. 새 기능·설정·독립 철학을 추가하지 않는다. 아래 출처와 적용 설명은 재검토 기록으로 보존한다.

**이전 상태: 재검토·미승인.** 사용자는 출처와 실제 제품에 대입할 때 달라질 경험을 물었다. 기존 승인 조건은 변경하지 않는다.

## 무엇에서 나온 제안인가

주 출발점은 롤스로이스의 Bespoke 주문 제작이다. 공식 2023년 사례는 고객의 상징색·가족의 기념·개인 관심사를 색상·소재·마감 등에 구현한다. [RR05 공식 원문](https://www.press.rolls-roycemotorcars.com/rolls-royce-motor-cars-pressclub/article/detail/T0438866EN?language=en)

이 자료는 개인의 의미와 취향이 제품에 반영되는 사례다. AI가 언어·자료·작업 목적에 자동으로 맞춘다는 기능이나 효과의 증거는 아니다. 이전 P07에는 필기구 적합성 자료 MB02·CW02도 섞여 있었으나, 사용자는 몽블랑 예시의 의미를 엘레강스함과 사용성으로 명확히 했다. 해당 자료를 사용자의 개인화 철학 의도로 해석하지 않는다.

## 중간 설명의 한계

개인 주문 제작에서 우리의 질문 목적에 맞는 결과 제공으로 넘어가는 과정은 조사자의 추론이다. 현재 목적에 맞는 결과를 만든다는 내용은 이미 P01의 의도·맥락을 활용한 처리에 상당 부분 포함된다. 별도 P07을 세우려면 어떤 새로운 고객 가치나 조건이 추가되는지 먼저 설명해야 한다. 장기 취향 학습·프로필 생성·개인 데이터 수집으로 임의 확대하지 않는다.

## 우리 제품에 대입할 수 있는 예시

| 사용자 요청과 상황 | 적용한다면 달라져야 할 경험 | 판단할 차이 |
| --- | --- | --- |
| 같은 자료를 두고 “이해하고 싶어”라고 요청 | 개념·관계·설명을 중심으로 결과를 구성 | 모든 요청에 동일한 요약 형식을 내보내는 대신 목적을 반영 |
| 같은 자료를 두고 “의견 차이를 비교해줘”라고 요청 | 주장별 차이·충돌·근거를 중심으로 구성 | 자료를 다시 고르고 결과를 비교표로 재가공하는 수고가 줄어드는지 |
| 비교 결과를 받은 뒤 “짧은 초안으로 이어줘”라고 요청 | 이미 정한 자료·목적·분량을 활용해 후속 결과를 구성 | 배경과 형식 조건을 다시 설명하게 하는지 |

이는 승인된 P01을 실행하는 적용 예시로 볼 수 있다. 새 기능 명세나 현행 동작의 품질 보증이 아니다. 명시된 목적이나 기존 맥락이 부족하면 제품이 취향을 단정하지 않는다.

## 현재 코드와 실제 수정 판단

- [prompt-library.ts](../../src/chat/prompt-library.ts)에 학습·연구·초안 등 작업 프리셋이 있다. 프리셋의 존재는 자동 개인화가 이미 된다는 증거가 아니다.
- [view.ts](../../src/chat/view.ts)는 현재 질문·이전 질문·세션 지침 등을 맥락 준비에 전달한다. [context.ts](../../src/chat/context.ts)는 지정 파일·폴더·작업 공간 참조를 처리한다.
- 수정이 필요하다면 기본 지침·기존 프리셋·맥락 전달이 실제 요청의 목적·형식·범위를 반영하는지 확인한다. 사용자에게 모드 선택을 새로 강제하거나 개인화 설정을 추가하는 것이 결론은 아니다.
- 기존 모델이 요청에 맞는 결과를 이미 제공한다면 이 예시만으로 새 코드 변경을 정당화하지 않는다. 부족한 동작이 확인됐을 때 관련 구현과 회귀 계약을 수정한다. 이번 검토에서 코드·모델 설정은 변경하지 않았으며 실제 모델 품질을 실행 평가하지 않았다.

## 정리 제안

P07의 현재 내용은 별도 철학보다 P01의 구체적인 적용 설명으로 정리하는 편이 낫다. 롤스로이스 Bespoke에서 더 넓은 개인화 가치를 가져오는 것은 별도 검토 대상이며, 지금 승인받은 것으로 취급하지 않는다. 사용자의 응답을 기다리는 재검토 상태다.
