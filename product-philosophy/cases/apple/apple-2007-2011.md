# 잡스 재임 말기의 애플: 기술의 결합이 작업을 완성하는 방식

상태: 조사 해석. 2010–2011년 중심, 2007년은 출발점 자료다. 현재 애플이나 이후 기능을 당시 철학의 직접 결과로 소급하지 않는다.

## 고객에게 보인 목적과 뒤에서 결합된 기능

| 작업 | 확인한 연결 | 출처 |
| --- | --- | --- |
| 전화·음악·인터넷 이용 | 여러 목적을 하나의 기기와 조작 방식으로 통합 | [AP01](../../sources/official.md#ap01) |
| 통화 상대를 보고 이야기하기 | 통화 흐름에서 영상 통화로 전환 | [AP02](../../sources/official.md#ap02) |
| 촬영한 내용을 다듬기 | 카메라와 편집 앱의 연결 | AP02 |
| 다른 기기에서 계속 읽기 | 읽던 위치·메모 등의 이어짐 | AP02 |
| 콘텐츠를 직접 읽고 다루기 | 앱·콘텐츠·화면 입력의 결합 | [AP03](../../sources/official.md#ap03) |
| 기기를 열고 바로 작업 시작 | 저장 장치·전력·휴대성의 결합 | [AP04](../../sources/official.md#ap04) |
| 같은 정보를 반복 옮기지 않기 | 앱 통합과 기기 간 자동 갱신 | [AP05](../../sources/official.md#ap05) |
| 준비 과정에서 컴퓨터 의존 줄이기 | 초기 설정·업데이트의 PC Free 경로 | [AP06](../../sources/official.md#ap06) |

**우리의 해석:** 시너지는 기능 목록의 합이 아니라 연결할 때 줄어드는 사용자 작업이다. “카메라가 있다”보다 “찍고 다듬어 쓸 수 있다”, “동기화가 있다”보다 “같은 내용을 다시 옮기지 않아도 된다”가 완성된 가치에 가깝다.

## 잘된 경험과 실제 제약을 함께 유지한다

- iPad의 직접 조작 경험을 긍정적으로 본 당시 시용 평가에서도 문서 이동과 동시 작업에는 불편이 있었다. [AP08](../../sources/independent.md#ap08)
- iPhone 4 수신과 표시 문제는 공식 설명에서도 다뤄졌다. 정교한 외형과 전체 동작 신뢰성을 같다고 판단할 수 없다. [AP07](../../sources/official.md#ap07)
- 후대의 회상에는 제품에 대한 애착과 잡스 시대의 결함을 되짚는 반론이 함께 있다. 향수는 역사 자료와 분리한다. [AP09](../../sources/community.md#ap09)
- 잡스 아카이브에는 2010년 iPad에 대한 직접 발언이 있으나 편집자 설명과 본인의 문장을 구분해야 한다. [AP10](../../sources/official.md#ap10)

당시의 단순한 경로를 기능 제거·닫힌 생태계·사용자 통제 축소의 정당화로 사용하지 않는다. 여러 기기와 서비스를 한 회사가 소유하는 구조를 그대로 복제해야만 시너지가 생기는 것도 아니다.

## 제품에 옮길 후보

P02는 작업을 시작할 준비와 즉각적인 반응, P06은 근거를 유지한 자료→답변→검토→활용의 연결, P10은 통합 약속의 정직함, P12는 적은 독립 기능이 아니라 목적의 명료함을 다룬다.

Rust/WASM에서 출처 위치가 사라지면 TS의 출처 버튼만으로 시너지를 복구할 수 없다. TS에서 결과를 활용할 때 위치 정보가 누락되면 검색의 정확성만으로 전체 작업을 완료했다고 할 수 없다. README나 영상이 실제로 연결되지 않는 단계를 연결된 것처럼 보여도 같은 원칙을 위반한다. 이 세 문장은 적용 후보이며 현재 구현의 상태를 진단한 결과는 아니다.
