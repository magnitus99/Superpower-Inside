# 롤스로이스: 편안함은 무엇이 만드는가

상태: 조사 자료. 브랜드 참조는 사용자가 지정했으며 실제 채택 범위는 [승인 기록](../../decisions/approved.md)을 따른다. 아래 차종·옵션·고객 가치 전체가 승인된 것은 아니다.

## 공식 가치와 확인한 구현

| 가치 축 | 구체적인 구현·사용 흐름 | 출처 |
| --- | --- | --- |
| 관리하지 않아도 이어지는 주행 | 노면 감지·서스펜션·변속을 함께 조율 | [RR01](../../sources/official.md#rr01) |
| 목적에 맞춘 복합 제어 | Cullinan의 오프로드 진입 행동이 여러 제어를 함께 활성화 | [RR02](../../sources/official.md#rr02) |
| 자신의 시간과 공간 | Phantom의 세부 마감·개인 Gallery, Extended의 승객 경험 | [RR04](../../sources/official.md#rr04), [RR12](../../sources/official.md#rr12) |
| 개인의 의미 | 기념·취향을 실제 주문 결과로 구현 | [RR05](../../sources/official.md#rr05) |
| 구매 이후의 안심 | 정비·보증·서비스 접점 | [RR06](../../sources/official.md#rr06) |
| 기술이 바뀌어도 같은 성격 | 전동화와 이후 개량을 기존 경험에 연결 | [RR03](../../sources/official.md#rr03), [RR13](../../sources/official.md#rr13) |

**우리의 해석:** 여러 기술이 사용자에게 하나의 일관된 감각으로 전달되는 것이 시너지다. 기술을 하나씩 제어하지 않아도 목적을 달성하게 하되 운전자의 필요한 선택까지 제거하지 않는다.

## 라인업은 같은 가치의 다른 적용이다

| 차종·변형 | 조사에서 구분한 사용 경험 | 그대로 일반화하지 않을 것 |
| --- | --- | --- |
| Phantom·Phantom Extended | 개인 공간·승객의 안락함·마감과 표현 | 모든 사용자가 수동적인 승객을 원한다는 가정 |
| Ghost·Ghost Extended | 편안함과 직접 운전의 균형, 개인화 | “롤스로이스는 운전 재미를 추구하지 않는다”는 단정 |
| Cullinan | 다양한 이동 상황에서도 목적에 집중하는 제어 | 목적 버튼 하나가 모든 상황을 무조건 해결한다는 약속 |
| Spectre·Spectre Series II | 기술 전환 뒤에도 이어지는 브랜드 성격 | 원형과 후속 제품의 정확한 사양을 혼합 |
| Black Badge | 더 강한 표현성과 역동성을 원하는 선택 | 차분함이 모든 사람에게 같은 기본 경험이라는 가정 |
| Wraith·Dawn | 역사적 쿠페·개방형 여행의 다른 경험 | 현행 차종 취급. 공식 종료 자료 RR10·RR11과 분리 |

현행 사이트 메뉴와 일부 공통 FAQ의 과거 차종 표기가 다를 수 있다. 라인업 판단은 해당 모델 본문과 날짜가 있는 종료 발표를 우선했다. 표는 철학 비교이며 지역별 주문 가능 목록이 아니다.

## 실제 경험과 반례

- 전문 시승에서는 매끄러운 주행과 단순한 제어의 만족이 보고된다. 특정 주행 성격과 노면에서는 절충이 있다. [RR07](../../sources/independent.md#rr07)
- 소유 지원을 좋아한다는 회원 자기 보고가 있다. 가입 자체에는 별도 단계가 있다. [RR09](../../sources/community.md#rr09)
- 중고 Ghost 소유자는 기능 문제와 여행 전 불안을 함께 보고했다. 브랜드의 안락함과 장기 무고장을 동일시할 수 없다. [RR08](../../sources/community.md#rr08)

## 제품에 옮길 후보와 검토 질문

- P01: 사용자는 목적을 선택하고 제품은 이미 허용된 범위 안에서 필요한 처리를 조율한다.
- P03·P04: 반복적인 준비와 불필요한 방해를 줄이되 중요한 실패는 드러낸다.
- P07: Bespoke는 기존 임베딩·프롬프트 설정의 개인 맞춤과 중복되어 독립 철학에서 제외했다. P09의 사용 과정 만족은 별도 승인됐으며 브랜드의 소유 의미 전체를 채택한 것이 아니다.
- P11: 첫 성공뿐 아니라 준비·사용·실패·복구까지 하나의 경험으로 책임진다.

고가·희소성·독점 회원 자격을 무료 오픈소스 제품의 운영 방식으로 자동 이식하지 않는다. 대신 그 요인들이 고객에게 주는 감정적 가치를 P09에서 따로 논의한다.
