# 조사 한계와 제외한 근거

85개 등록 출처는 본문을 열어 확인하고 필요한 구간을 요약했다. 원문 전체나 이미지·영상은 저장하지 않았다. 제목·링크·확인 구간·날짜·요약·해석 한계를 남겼다. 이후 원문이 바뀌거나 삭제되면 링크 재확인과 요약 갱신이 필요하다.

## 자료 접근이 부족해 주요 판단에 쓰지 않은 것

- Fountain Pen Network의 Montblanc 149 견고성 비교: 검색에 노출됐으나 본문 접근은 403이었다. 견고성 결론에 사용하지 않았다.
- Montblanc의 일부 개인 소유 후기: 검색 발췌만 확보되고 본문 접근에 실패한 글은 주요 출처 대신 본문이 확인된 다른 토론으로 대체했다.
- Pelikan의 일부 제품 사양 데이터 페이지: 본문 접근 실패로 세부 사양의 근거로 사용하지 않았다. 공식 컬렉션 페이지의 확인 범위만 썼다.
- Maybach 도어 조작의 지역별 온라인 매뉴얼: 페이지는 열렸으나 실제 조작 본문을 확보하지 못했다. 검색 발췌에 나온 취소 제스처는 원칙 근거로 사용하지 않았다.
- Bentley의 일부 중고차 운행 토론, Team-BHP의 Maybach 시용 글: 본문 확보에 실패해 출처 레지스트리에 넣지 않았다.
- Montblanc StarWalker의 과거 제품 URL: 현재 카테고리로 이동했다. 과거 제품의 정확한 외형·무게·가격은 근거로 사용하지 않고 관리 문서의 모델별 사용 방식만 확인했다.

- Nest의 일정 관련 커뮤니티 글과 Beosound Balance의 일부 토론은 검색 발췌만 확보되고 본문 확인에 실패했다. 출처 레지스트리에 넣지 않았다. Nest 사례는 공식 동작 계약만 확인했으며 고객 만족도 판단은 보류했다.

## 아직 알 수 없는 것

- 각 브랜드의 평균 만족도, 고장률, 유지비, 실제 서비스 평균 소요 시간.
- 후기 작성자의 소유 여부, 잉크·종이·차량 상태·기기 설정, 조작된 후기 여부.
- 특정 브랜드의 고객 가치가 우리 사용자에게 동일하게 작용하는지 여부.
- 조사한 모든 제품의 최신 지역별 사양·옵션·요금·지원 범위.
- 우리 제품의 실제 준비 시간·전환 부담·출처 연결 보존율·반복 사용 만족도.

공식 소개가 같은 사이트 안에서도 날짜가 있는 발표·현행 모델 본문·공통 FAQ 사이에 달라질 수 있다. 역사적 기능 설명과 현재 문서도 구분했다. `published_on: null`은 날짜를 확인하지 못했다는 뜻이며 최근 자료라는 뜻이 아니다.

## 이번 단계의 완료 범위

사용자가 지정한 출발점과 명시한 비교 범위의 1차 자료 수집·분류·후보화까지다. 사용자가 직접 지정한 세 핵심 방향은 철학 문서에 반영했다. P01은 사용자 역할의 자동화를 포함하는 조건으로 확정했다. P02는 기본 품질 조건으로 승인됐고 P03은 P01의 중복 설명이다. P04는 사용자의 주의를 목적과 결과에 두는 방향으로 승인됐다. P05는 전체 흐름의 편안함을 기준으로 승인됐고 P06은 P01의 중복 설명이다. P07은 중복 독립 철학에서 제외했고 P08은 현행 계약이다. P09는 사용 과정의 만족을 고객 가치로 승인했다. 초기 15개 후보의 나머지는 선행 기준에 포함되는 적용 설명으로 정리했다. 비교 제품의 특성 전체를 승인한 것은 아니며 코드·모델 설정·README·영상·마케팅 문구에 적용하지 않았다. 철학 게이트도 실행하지 않았다.
